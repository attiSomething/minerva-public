Using Minerva to Organize Files

Your library is ordinary folders and text files. Minerva reads that layout, adds a few things a folder can't hold (like flags), and gives you tools to tidy it without ever deleting anything.

1. Categories

Each top-level folder (Fiction, Nonfiction, Poetry, Misc) is a category. To move an entry, open it and change its Category; Minerva moves the folder for you.

2. Find anything on the Entries page

Search by title, and filter by category, project, published or the To Edit and To Record flags. Click a row to open the entry.

3. Group entries into projects

A project is a collection, like a chapbook or a series. Create one on Projects, then add entries from the project page or from an entry's Project panel. The entry's folder gets a short tag such as - [MB], so the grouping shows in Explorer too. Put a project's entries in reading order on its page.

4. Flag what needs doing

Tick To Edit or To Record, or mark an entry Published and note where. Flags live in Minerva's index, and the Entries page can filter by them.

5. Clear up duplicates

Duplicates, at the top of the Entries page, lists pieces that look alike. Read both side by side, then mark them as not duplicates, confirm them, or merge them. Merging moves the other entry's whole folder into this one's Archive, so nothing is lost.

Good to know: rename and move entries through Minerva rather than Explorer. Minerva keeps their flags and links; a folder renamed outside it looks like a new entry.
